suite must pass cleanly on the remediation branch before tagging. The
marketplace submission pulls from the released open-source repo, so green here
== green there. This doc captures the pytest result so it can be lifted
verbatim into the release notes. It lives under `notes/` and therefore does
**not** ship in the release artifact (see ADR 0002).

> **Note on running the suite:** the tests must run under an interpreter where
> the host `code_puppy` framework is importable. `tests/conftest.py` registers
> the working tree as `code_puppy.plugins.bead_chain` and several
> lifecycle/register tests import `from code_puppy.plugins.wiggum import ...`.
> A bare `pytest` from a venv without `code_puppy` installed fails at conftest
> import time with `ModuleNotFoundError: No module named 'code_puppy'` — that is
> an environment issue, not a test failure.
