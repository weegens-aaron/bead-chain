# bead-chain Documentation (Maintainer Edition)

**bead-chain** is a beads-driven `/goal` variant that chains your `bd ready` queue into wiggum's goal loop, one bead at a time — no manual bead juggling, no lost context, no forgotten commits.

This guide is for **maintainers and developers** working on bead-chain itself. It includes implementation details, architecture, source paths, and internal mechanics.

---

## Four Ways to Learn

### [Tutorials](tutorials/) — Learn by doing
Get bead-chain running on your machine with step-by-step guidance. **What it's for:** hands-on setup and first experience.

### [How-to Guides](how-to/) — Solve real tasks
Recipes for integrating bead-chain into a project, debugging stuck work, and handling edge cases. **What it's for:** accomplish goals with code you already understand.

### [Reference](reference/) — Look things up
Technical description of architecture, modules, configuration, command syntax, and internals. **What it's for:** understand the machinery and how to operate it.
